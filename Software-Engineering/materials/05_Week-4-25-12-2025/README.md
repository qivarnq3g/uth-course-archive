### Instructrions for making group projects

Nguồn: [Moodle](https://courses.ut.edu.vn/mod/page/view.php?id=454078)

> * Requirements:
> Stage 1 – Analysis and Specification of Requirements:
>
> Use natural language to describe functional and non-functional requirements. Draw DFD (Data Flow Diagrams), Use Case Diagrams, and Class Diagrams.
>
> Stage 2 – Design:
>
> Design the user interface (if any). If the program is a console application, describe the interface in text form. Design the database: define tables, primary keys, and foreign keys.
>
> Stage 3 – Implementation:
>
> Use programming languages such as Python / C++ / Java.
>
> Stage 4 – Testing:
>
> Create a set of test cases, debugging, and bug management.
>
> *Tools that can be used:
> Document, source code, and team management: GitHub / GitLab
> Drawing DFD, Use Case, Class Diagram, and Database Schema: https://app.diagrams.net/
> Programming IDEs: VS Code / Visual Studio / PyCharm / Eclipse / …
> Creating test cases: Excel
> Bug tracking tools: Jira / Bugzilla / Mantis Bug Tracker
> Packaging and deployment: Docker
> Other tools may also be used.
> *The Structure of a Requirement Specification & Design Document:
> Functional Requirements
> Non-Functional Requirements
> Data Flow Diagram
>  Use case Diagram
>  Class Diagram
> Data Model
> Interface Design Description
