> Course Objective:
> The Computer Architecture subject belongs to the basic technical knowledge block of the IT industry and the Computer Network and Data Communications industry.
> After completing this subject, students can:
> 2.1   Knowledge: - Presents basic general knowledge and evolution of computer generations, examines performance issues, details components of computer systems: internal connections within the computer, cache memory , internal memory, external memory, input/output devices, counting system, instruction set, Intel x86.
> 2.2   Skills: Solve technical problems in computer architecture through using EMU assembly language programming software; Work effectively in teams, communicate and read technical documents.
> Course description:
> This course consists of 6 chapters:
> -          Chapter 1-5:  Provide basic knowledge about computer structures.
> -          Chapter 6: Provide skills for assembly language x8086 by EMU software.
