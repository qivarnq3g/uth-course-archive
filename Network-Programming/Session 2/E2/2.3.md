BT 2.3 - DoubleChatTCP
Viết chương trình Chat giữa 2 Client với nhau. Yêu cầu:

oServer chờ đủ 2 Client kết nối đến qua cổng 9999

oClient 1 gửi thông điệp đến Client 2 thông qua Server (Client 1 là Client kết nối đến Server trước)

oClient 2 gửi ngược lại thông điệp cho Client 1 cũng thông qua Server

oĐặt tên Solution/Projects lần lượt là: DoubleChatTCP
